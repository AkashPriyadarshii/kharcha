# Security Policy

## Supported Versions

We currently only support the latest release of the application. Please ensure you are updated to the latest version before reporting issues.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

Security is a top priority for Kharcha. If you discover a security vulnerability, please do not disclose it publicly.

Instead, please send an email to the repository owner immediately or use the in-app Bug Reporting tool (available in Profile -> Settings -> Report a bug) marking it as a critical security issue.

We will try to acknowledge your report within 48 hours and work with you to resolve the issue promptly.
